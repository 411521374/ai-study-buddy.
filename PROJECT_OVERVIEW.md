# Project overview

**Project:** StudyBuddy — an AI-assisted learning companion  
**Audience:** University and college students  
**Purpose:** Put five study workflows in one simple website.

## Tools
- HTML, CSS and JavaScript for the interface
- Node.js built-in HTTP server
- Optional server-side AI chat endpoint
- Browser local storage for study planner tasks

## Demo limitations
Prepared chat examples, a small quiz bank, a few grammar rules, and extractive notes outline. See README for optional live AI setup and limitations.
