# StudyBuddy — Presentation Script

**Slide 1 — Introduction**
Hello everyone. My project is called StudyBuddy. It is an AI-assisted learning companion designed to help students with everyday study tasks.

**Slide 2 — The problem**
Students often use different tools for asking questions, reviewing notes, practising quizzes and planning their work. Switching between tools can make studying feel less organized. StudyBuddy brings these activities into one simple workspace.

**Slide 3 — Target users**
The main users are university and college students. It can also help people practising English or anyone who wants to study at their own pace.

**Slide 4 — Features**
There are five features. Study chat explains a topic. The quiz generator creates practice questions and checks answers. The notes tool makes a short outline from pasted notes. English practice checks a few common grammar patterns. The planner helps students track tasks.

**Slide 5 — How it works**
A student enters a question or some study material. The website processes it and shows a response. The prototype has a demo mode that works without an API key. It also includes an optional server-side AI connection. The API key stays on the server.

**Slide 6 — AI in development**
I used ChatGPT to help plan the project, draft and refine code, and prepare example interactions and documentation. AI-generated code and content still need to be checked.

**Slide 7 — Testing and limitations**
The quiz flow, planner interactions and main tool interfaces are included in the prototype. Demo mode has limitations: the quiz bank is small, grammar checks cover only a few patterns, and note summarization is extractive. Live AI requires a private API key and should only be described as tested after a successful live request.

**Slide 8 — Next steps**
In the future, I would connect every tool to a live AI service, generate quizzes from uploaded notes, improve language feedback, and ask students to test the website.

**Slide 9 — Closing**
That is my project, StudyBuddy. The main idea is to make independent study clearer and more organized. Thank you. Do you have any questions?
